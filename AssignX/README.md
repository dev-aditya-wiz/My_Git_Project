# AssignX

Premium assignment-management dashboard prototype for college students.

## Stack
- HTML5
- CSS3
- Inter via Google Fonts
- No backend
- No required JavaScript

## Structure
- `index.html` — login / entry page
- `dashboard.html` — main dashboard
- `assignments.html` — assignment table and filters
- `assignment-details.html` — assignment details
- `submit.html` — upload and submission states
- `calendar.html` — deadline calendar
- `history.html` — submission timeline and feedback
- `notifications.html` — notification center
- `profile.html` — student profile
- `css/style.css` — design system and global styles
- `css/components.css` — reusable UI components
- `css/dashboard.css` — dashboard-specific styles
- `css/responsive.css` — responsive refinements

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
This is a visual HTML/CSS prototype. Forms, upload controls, filters and navigation are intentionally presented as realistic UI states; there is no backend or fake persistence.
